# whistle-rs 示例规则文件
#
# 语法：<匹配模式> <协议>://<参数> ...
# 用法：w2r start --rules examples/rules.txt
#
# 当前已实现的协议：
#   转发/Mock : host  redirect  file  rawfile  statusCode
#   头/Cookie : reqHeaders resHeaders reqCookies resCookies reqType resType ua referer attachment
#               forwardedFor  headerReplace  delete  reqCharset  resCharset
#   Body 改写 : reqBody resBody reqReplace resReplace *Prepend *Append html*/js*/css*
#   状态/方法/查询 : replaceStatus  method  pathReplace  locationHref
#   时延      : reqDelay  resDelay
#   其它      : urlParams  auth  reqCors  resCors

# 1) 把某域名的流量转发到本地服务（host:// 覆盖上游目标，保留原 Host 头）
www.example.com host://127.0.0.1:8080

# 2) 转发并注入响应头（多个用 & 连接）
api.example.com host://127.0.0.1:3000 resHeaders://x-from=whistle-rs&access-control-allow-origin=*

# 3) 用本地文件 mock 接口返回（按扩展名推断 Content-Type）
api.example.com/config file:///tmp/config.json

# 4) 直接返回状态码（mock，无 body）
example.com/maintenance statusCode://503

# 5) 302 重定向
old.example.com redirect://https://new.example.com

# 6) 正则匹配：拦截所有图片请求返回 404
/\.(png|jpe?g|gif|webp)(\?.*)?$/ statusCode://404

# 7) 通配符匹配子域名 + 覆盖 UA / 注入请求头
*.test.example.com ua://whistle-rs/0.0 reqHeaders://x-debug=1

# 8) 改写响应体：字符串替换 + 注入脚本
example.com/page.html resReplace://OLD=NEW htmlAppend://<script>console.log('injected')</script>

# 9) 注入 CORS 响应头、补 Basic 鉴权、追加查询参数
api.example.com resCors://* auth://user:pass urlParams://debug=1

# 10) 模拟弱网：请求/响应各延迟 500ms；并改写返回状态
slow.example.com reqDelay://500 resDelay://500 replaceStatus://200

# 11) 伪造来源 IP、删除响应 Server 头、改写 UA 中的关键字
secure.example.com forwardedFor://1.2.3.4 delete://resHeaders.server headerReplace://user-agent=Mozilla|whistle-rs

# 12) 改写请求路径段、并覆盖响应 location 头
api.example.com pathReplace:///v1|/v2 locationHref://https://cdn.example.com/asset
