# Vendored whistle Web UI

These are the **prebuilt** frontend assets from [whistle](https://github.com/avwo/whistle)
(npm `whistle@2.10.4`, MIT License, © avwo), served as-is by whistle-rs when
`--ui whistle` is used. whistle-rs implements a whistle-compatible `/cgi-bin/*`
backend to drive this UI. See crates/whistle-web/src/whistle_compat.rs.
